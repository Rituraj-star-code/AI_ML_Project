# 🎓 AI-Powered Student Performance Prediction & Analytics

An intelligent, data-driven web application designed to analyze student academic performance, predict outcomes using Machine Learning, and provide meaningful insights through an interactive analytics dashboard.

## 📌 About The Project

The **AI-Powered Student Performance Prediction & Analytics** system aims to help understand and evaluate students' academic performance using data analytics and machine learning techniques.

The application analyzes various academic and behavioral parameters, including attendance percentage, assignments completed, class participation, and other relevant student-related attributes.

By utilizing Machine Learning algorithms, the system predicts student performance and transforms raw academic data into meaningful insights through an interactive web-based dashboard.

The primary objective is to identify students who may require additional academic support, understand performance patterns, and assist educators in making data-driven decisions.

## 🎯 Project Objectives

- Predict student academic performance using Machine Learning.
- Analyze student performance based on multiple academic parameters.
- Identify students who may require academic attention.
- Visualize student performance through an interactive dashboard.
- Maintain student records and prediction history.
- Provide meaningful insights through data analytics.
- Support better academic planning and decision-making.

## ✨ Key Features

- **Student Performance Prediction:** Predicts student performance using trained Machine Learning models.
- **Interactive Dashboard:** Displays important academic statistics and performance indicators.
- **Student Analytics:** Analyzes attendance, assignment completion, participation, and other academic parameters.
- **Performance History:** Maintains historical prediction records.
- **Model Performance Analysis:** Displays machine learning model evaluation metrics.
- **Data Visualization:** Presents academic insights through graphical representations.
- **Database Integration:** Stores student information and prediction history using MySQL.
- **Dynamic Analytics:** Updates dashboard information based on available student records and model metadata.

## 🏗️ System Architecture

The project follows a layered architecture consisting of the following components:

1. **Frontend Layer:** Provides an interactive interface for entering student information and displaying analytical results.
2. **Backend Layer:** Uses Flask to handle application requests, process input data, and communicate with the machine learning and database layers.
3. **Machine Learning Layer:** Processes student-related features and generates performance predictions using trained models.
4. **Database Layer:** Uses MySQL to store student records and prediction history.
5. **Analytics Layer:** Generates performance statistics, visualizations, and model evaluation information for the dashboard.

## ⚙️ Working Process

1. Student-related information is entered into the application.
2. The backend receives and validates the submitted information.
3. Relevant features are processed and passed to the trained Machine Learning model.
4. The model generates a performance prediction.
5. Student information and prediction results are stored in the MySQL database.
6. The dashboard displays updated statistics, analytics, and performance insights.
