1. Dataset Overview

The project dataset contains 2,000 student records and 12 columns, including academic information and target variables.

Input features:

  • Age and attendance percentage
  • Study hours per week
  • Previous grade
  • Total and completed assignments
  • Internal marks and quiz average
  • Class participation score

Target variables:

  • Final score – Regression
  • Final grade – Classification

2. Machine Learning Workflow

  1. Dataset collection and loading
  2. Exploratory Data Analysis (EDA)
  3. Missing-value handling and preprocessing
  4. Feature preparation
  5. Model training and evaluation
  6. Model serialization using Joblib
  7. Prediction through Flask API
  8. Storage and retrieval using SQLite
  9. Visualization through the web dashboard

3. Technologies Used

  • Python: Main programming language
  • Pandas & NumPy: Data processing
  • Scikit-learn: Machine learning models
  • Matplotlib & Seaborn: Data visualization
  • Joblib: Saving and loading trained models
  • Flask: Backend API and application server
  • SQLite: Prediction record storage
  • HTML, CSS & JavaScript: Frontend
  • Chart.js: Interactive dashboard charts
